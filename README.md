# Portfoliooptimierung-mit-Kryptowaehrungen

Dieses Repository enthält den R-Code der Bachelorarbeit zur empirischen Analyse der Portfoliooptimierung mit Kryptowährungen.

Die benötigten R-Pakete werden beim Ausführen des Skripts automatisch installiert, sofern sie noch nicht vorhanden sind.

Die verwendeten Marktdaten werden über Yahoo Finance abgerufen.

Erzeugte Tabellen und Abbildungen werden automatisch im Ordner `Plots_Bachelorarbeit` gespeichert.
